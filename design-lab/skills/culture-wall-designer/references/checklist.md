# Culture Wall Design — Quality Checklist

## P0 (Must Pass)

| # | Check | Verification |
|---|---|---|
| 1 | Brand color accuracy | ΔE ≤ 3 vs brand spec |
| 2 | Information hierarchy | 3 levels: far (3m+), mid (1.5-3m), near (0.5-1.5m) |
| 3 | Lighting uniformity | Min/Avg ≥ 0.7 per GB 50034-2024 |
| 4 | Information density | Text/graphics ≤ 40% of wall area |
| 5 | Wheelchair reach | Core content at 0.9-1.2m height |
| 6 | Color contrast | All text ≥ 4.5:1 (WCAG AA) |
| 7 | Anti-slop | No purple gradients, emoji icons, left-border cards |
| 8 | Typography | Display ≠ Body; no Inter/Roboto as display |

## P1 (Should Pass)

| # | Check | Verification |
|---|---|---|
| 9 | Material finish | Matte/brushed/polished specified |
| 10 | CRI requirement | ≥ 95 for color-critical zones |
| 11 | Wayfinding integration | Connects to building architecture |
| 12 | Content owner | Each zone has update contact |
| 13 | Installation method | Wall-mounted/stand-alone/suspended |

## P2 (Nice to Have)

| # | Check | Verification |
|---|---|---|
| 14 | Night mode | After-hours lighting scenario |
| 15 | Physical samples | Material swatch references |
| 16 | Cost estimate | Range provided |
| 17 | Maintenance | Cleaning/replacement schedule |
