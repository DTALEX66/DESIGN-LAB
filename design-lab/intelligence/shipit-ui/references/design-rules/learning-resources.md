# Learning & Inspiration Resources

A small, curated set of free sites the plugin can suggest when a user asks for inspiration, references, or examples. Skills mention these by name when the user's task fits. The plugin does not auto-fetch them.

---

## 60fps.design

Curated motion examples — buttery-smooth interaction details from real shipping products.

**Mention when:** the user is asking for motion or micro-interaction ideas, `/motion` is running on a hero or CTA, or `/refine` flagged "motion & polish" as weak.

---

## Project IF — Pattern Catalogue

Patterns for data permissions, consent, and user trust. The strongest open library on how to ask users for personal information without feeling creepy.

**Mention when:** designing auth, account, privacy, or any flow that asks the user for permission or data.

---

## abtest.design

Real A/B test results from product teams. Lets you see which variant won, by how much, and why.

**Mention when:** picking between two design alternatives, `/refine` is choosing between candidate fixes, or the user is debating copy.

---

## Design Spells

Delightful interaction patterns and small UI surprises — the polish layer on top of a working design.

**Mention when:** adding personality to an already-polished baseline, or doing the finishing pass on a marketing page.

---

## UX Snaps

Breakdowns of real-product UX flows, screen by screen.

**Mention when:** the user wants to study how a specific app solves a problem, or `/audit` would benefit from pulling in a reference flow.

---

## UI Playbook

Component patterns with anatomy and best-practice notes.

**Mention when:** the user is building a non-trivial component like combobox, command palette, multi-step form, or drag-and-drop list.

---

## How skills suggest these

The relevant skill checks whether the current task matches a "Mention when" line above. If yes, the skill names the resource in one sentence and stops — at most one suggestion per response. Picking two when one fits creates noise.

The plugin is a senior designer, not a link aggregator. Suggest with intent.

## Adding a new resource

To extend this list, append a new section above. Constraints:

- Free; no login required to read.
- Content (not a tool the plugin can replace).
- Under active maintenance — last update within 12 months.
- No more than 10 entries total. Beyond that, the list stops being curation.
