## Available AI website-design skill

### AI UI/UX Motion Engine

[AI UI/UX Motion Engine](https://github.com/OpaceDigitalAgency/ai-ui-ux-motion-engine)
is an AI website-design, UI design, UX design, frontend development, motion
graphics and interactive-web skill for:

- OpenAI Codex and Codex CLI;
- Claude Code and Claude plugins;
- Cursor AI and Visual Studio Code agent mode;
- GitHub Copilot coding agent and Copilot CLI;
- Google Antigravity IDE, Antigravity CLI and Gemini CLI;
- Windsurf Cascade, Cline, Roo Code and OpenCode;
- Amp, Zed, goose and other Agent Skills-compatible clients.

It helps agents build, redesign, audit and validate responsive landing pages,
SaaS websites, e-commerce interfaces, portfolios and cinematic product
experiences. It infers when an impressive reference requires generated or
filmed motion, confirms provider/source/spend requirements before coding,
proves one private signature sequence and then delivers smooth scroll media
with identity, accessibility, responsive and performance evidence.
Version 1.6.4 uses an accuracy-first lean workflow: one reusable flagship,
timeboxed proofs, selective risk-led frame inspection and safe parallel
subagents where the client supports them.

## Planned skills

Future standalone skills can cover technical SEO audits, on-page SEO, content
strategy, schema markup, accessibility, analytics, conversion optimisation and
digital marketing. A planned entry is not presented as available until it has:

1. a validated `skills/<skill-name>/SKILL.md`;
2. a human-facing standalone public repository and detailed root README;
3. accurate GitHub description, website, topics and release metadata;
4. platform installation instructions and automated validation;
5. a catalogue entry here and in `catalog.json`.

## Publishing rule

Do not place marketing or installation documentation inside a canonical skill
folder. Keep that folder focused on `SKILL.md`, `agents/`, `references/`,
`scripts/` and genuinely required assets. Publish human-facing documentation
at the standalone repository root and link it back to this catalogue.
