# Knowledge Lifecycle

| State | Meaning | Runtime eligibility |
| --- | --- | --- |
| registered | Source and rights record exists | No |
| extracted | Bounded extraction produced local cache/output | No |
| normalized | Structured candidate formed | No |
| candidate | Awaiting human review | No |
| reviewed | Rights and content reviewed | Yes, through a projection or compiled target |
| compiled | Converted into a governed target | Yes |
| rejected / quarantined | Not eligible for use | No |

Only the defined forward transitions are permitted. Provenance must link source, extraction, reviewed record, compiled target, and usage evidence.
