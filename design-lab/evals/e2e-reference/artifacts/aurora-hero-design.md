# AURORA 电商 Hero 主图设计交付文档

**尺寸:** 1920×1080 · **色彩空间:** sRGB · **格式:** PNG + WebP

---

## 1. 设计意图

以"深空中的第一道光"为概念核心，用高对比暗色基底衬托品牌哑光金质感，传递 luxury-premium 定位。画面通过大面积留白建立呼吸感，主视觉聚焦于产品本身，辅以极简排版制造"少即是多"的克制奢华气质，适用于天猫/京东/独立站首屏轮播首帧。

## 2. 构图方案

### 三分法主结构

```
┌───────┬───────┬───────┐
│       │       │       │
│  LOGO │ 光效  │  促销 │  ← 上三分线
│ (左上) │ 焦点  │ 信息  │
├───────┼───────┼───────┤
│       │       │       │
│ 留白  │ 产品  │ 留白  │  ← 中心区
│       │ 主体  │       │
├───────┼───────┼───────┤
│       │       │       │
│ 品牌  │ CTA   │ 辅助  │  ← 下三分线
│ 故事  │ 按钮  │ 标签  │
└───────┴───────┴───────┘
```

### Z 型视觉动线

1. **起点** — 左上 LOGO / 品牌标识（视线入口）
2. **横移** — 右上促销利益点（限时折扣/赠品）
3. **对角线下行** — 至画面中央产品主体（最大停留区）
4. **终点** — 右下 CTA 按钮 + 左下品牌 slogan（行动引导）

> 产品主体置于画面几何中心略偏右下 5%，与三分线交叉点重合，确保视觉重量平衡。

## 3. 色彩与字体规范

### 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| **深空基底** | `#1A1A2E` | 主背景，占画面 ≥70% |
| **哑光金** | `#C9A96E` | LOGO、标题、CTA 边框、装饰线 |
| **暖白** | `#F5F0EB` | 正文、辅助文案 |
| **微光金** | `#E8D5A3` | 光效高光、渐变中间态 |
| **暗调辅色** | `#16213E` | 背景渐变过渡层 |

背景建议采用 `#1A1A2E → #16213E` 径向渐变（中心偏左上），模拟深空微光氛围。光效层使用 `#E8D5A3` 低不透明度（8–15%）羽化圆。

### 字体规范

| 层级 | 字体 | 字重 | 字号 | 色值 |
|------|------|------|------|------|
| 主标题 | 思源宋体 Heavy | 900 | 72–96px | `#C9A96E` |
| 副标题 | 思源宋体 Bold | 700 | 36–48px | `#F5F0EB` |
| 正文/说明 | 思源宋体 Regular | 400 | 18–24px | `#F5F0EB` 80% |
| CTA 按钮 | 思源宋体 Medium | 500 | 20–28px | `#1A1A2E` |
| 促销标签 | 思源宋体 Bold | 700 | 48–64px | `#C9A96E` |

行高：标题 1.2 / 正文 1.6。字间距：标题 +2% / 正文默认。

## 4. 生产规格

| 项目 | 规格 |
|------|------|
| 画布尺寸 | 1920 × 1080 px |
| 色彩空间 | sRGB IEC61966-2.1 |
| 位深度 | 8-bit |
| 安全区 | 四边各 80 px（核心内容区 1760×920） |
| 导出格式 | PNG-24（交付主文件）+ WebP（线上加载用） |
| 压缩 | WebP quality 85；PNG 无损 |
| 命名 | `AURORA_hero_1920x1080_v{X}.{ext}` |

### 安全区说明

80px 安全区（约画面高度 7.4%）兼容各平台裁切安全边距。LOGO、主标题、CTA 按钮、促销角标必须落于安全区内；背景光效与装饰性元素可延伸至出血区。
