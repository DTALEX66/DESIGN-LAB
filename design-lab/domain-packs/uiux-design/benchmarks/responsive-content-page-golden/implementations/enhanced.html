响应式设计中的可读性工程：从 320 到 1280

2026-08-11 ｜ 阅读约 8 分钟

引言

可读性不是字体大小的附属品，而是排版、间距、行宽与断点共同作用的结果。在移动优先的时代，内容页必须同时服务 320px 的窄屏读者与 1280px 的桌面研究者。

设计原则

  • 行宽控制：正文行宽保持 60–80 字符，超宽自动分栏。
  • 层级分明：标题/正文/引用的字号与字重形成清晰节奏。
  • 溢出治理：代码块与表格在窄屏横向滚动，而非压扁。
可读性设计的终点不是"能读"，而是"读得舒服、读得下去"。

Token 与可访问性

所有颜色、间距与字号均来自 DTCG Token，保证对比度 ≥ 4.5:1（正文）且支持 reduced-motion。

代码示例

:root {
  --text: #111827;
  --accent: #0F6BFF;
}
h1 { font-size: clamp(26px, 4vw, 38px); }
.prose p { max-width: 66ch; }

对比表格

断点布局TOC表格
320–767单栏隐藏（可展开）横向滚动
768–1199单栏 + 窄侧栏固定侧栏横向滚动
≥ 1200双栏sticky 侧栏全宽

小结

响应式内容页的关键不是"每个断点都好看"，而是让内容在任何宽度下都保持可读、可导航、无障碍。这正是本案例（V42-0406）的验收标准。
