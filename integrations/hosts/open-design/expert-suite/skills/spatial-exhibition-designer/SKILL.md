# 个人空间与展陈设计专家

先规划访客路径、视线和叙事分区，再设计墙面图形。每区必须有一句命题和一个视觉锚点；数字媒体必须有静态降级；材质、照明、可维护性和无障碍必须进入方案。

## 设计规范

### 1. 照度标准 (GB 50034-2024 + CIE 157)

| 场所/材料 | 推荐照度 | 年曝光限制 |
|---|---|---|
| 极敏感（纺织品、纸张、照片） | 50 lux | ≤ 30,000 lux·h/年 |
| 中等敏感（油画、皮革） | 150-200 lux | ≤ 60,000 lux·h/年 |
| 稳定材料（金属、石材） | 300 lux | 无限制 |
| 展厅一般照明 | 200-500 lux | — |
| 文化墙立面 | 150-300 lux | — |
| 导视标识 | 200-500 lux | — |
| 互动触摸屏 | 300-500 lux | — |

### 2. 光源参数

- **CRI (显色指数)**: ≥ 90（展厅），≥ 95（博物馆级）
- **R9 (红色显色)**: ≥ 50（展厅），≥ 95（博物馆级）
- **色温**: 2700K-4000K（展厅），可调色温 2700K-5000K
- **UV 辐射**: < 75 μW/lm
- **IR 辐射**: 最小化
- **眩光**: UGR < 19（展厅），UGR < 16（博物馆）

### 3. 照明方式

- **一般照明**: 均匀照度 200-500 lux
- **重点照明**: 立面 150-300 lux，30° 入射角
- **洗墙照明**: 灯具距墙 1/3-1/6 墙高
- **展柜照明**: 内部 50-200 lux（敏感物品）
- **导视照明**: 背光/侧光，200-500 lux
- **智能控制**: DALI-2 骨干 + Casambi 无线 + DMX 场景

### 4. 材质选择规范

| 材料 | 特性 | 适用场景 | 加工方式 |
|---|---|---|---|
| 亚克力 (PMMA) | 多色、耐候性中等 | 展板、标识、展柜 | 激光切割/丝印/数码打印/热弯 |
| 铝 | 轻质、耐腐蚀、耐用 | 框架、面板、标识 | 粉末涂层/阳极氧化/数码打印 |
| 不锈钢 | 高端、极耐用 | 高端室内外 | 拉丝/抛光/喷涂 |
| PVC foam board | 轻量、低成本 | 临时/低成本展板 | 数码打印/UV 打印 |
| 玻璃/陶瓷 | 高端、耐用、易清洁 | 触觉标识、展柜 | 丝印/烤花 |
| 木材 | 温暖、自然、需处理 | 文化墙、接待台 | 雕刻/路由/贴膜 |
| LED 灯箱 | 均匀发光、可更换画面 | 大型展板、背景墙 | 数码打印/UV 打印 |

### 5. 导视设计规范

#### 观看距离与字体大小

| 观看距离 | 最小字高 | 适用场景 |
|---|---|---|
| < 1m | 10mm | 说明文字 |
| 1-3m | 25mm | 区域标题 |
| 3-6m | 50mm | 主标题 |
| 6-10m | 100mm | 展厅标识 |
| > 10m | 150mm+ | 建筑标识 |

#### 导视设计原则

1. **远读/中读/近读** 三级信息层次
2. **色彩对比度**: WCAG AA（4.5:1），AAA（7:1）
3. **字体选择**: 无衬线体（中文：思源黑体、苹方）
4. **盲文/触觉**: 关键标识需包含
5. **照明**: 避免眩光，30° 入射角

### 6. 文化墙设计规范

#### 空间尺度
- **层高**: 2.4m-4.5m（常规），4.5m+（高端）
- **观看距离**: 1.5m-3m（主立面），3m-6m（次立面）
- **通道宽度**: 主通道 ≥ 2.4m，次通道 ≥ 1.8m

#### 设计原则
1. **叙事动线**: 起承转合，有节奏感
2. **视觉锚点**: 每 3-5m 一个视觉焦点
3. **留白**: 信息密度 ≤ 40%，呼吸感
4. **模块化**: 可更换、可升级
5. **无障碍**: 轮椅可及高度 0.9m-1.2m

#### 常见布局系统
- **时间轴 ribbon**: 历史/进程/成就
- **模块化网格**: 价值观/荣誉/团队/产品
- **Hero statement**: 大标语 + 证明模块
- **博物馆条**: 标题/文物/说明/序列
- **分层浮雕**: 2D 图形 + 立体字 + 灯光
- **互动墙**: QR/LED/触摸/旋转内容

### 7. 3D 渲染规范 (Blender 5.2+)

#### 推荐工作流
```
展厅 3D 工作流:
1. 空间建模（墙体、天花板、地板、展柜）
2. 材质设置（金属、玻璃、木材、亚克力、LED）
3. 灯光布局（区域光、IES 配置、HDRI）
4. 摄像机设置（参观动线、焦点）
5. 渲染输出（EEVEE 实时 / Cycles 照片级）
6. 后期合成（色彩校正、景深）
```

#### 材质参数
- **金属**: roughness 0.1-0.3, metallic 1.0
- **玻璃**: IOR 1.5, roughness 0-0.1
- **亚克力**: IOR 1.49, roughness 0-0.05
- **木材**: roughness 0.4-0.8
- **LED 面板**: emission 1.0-5.0

### 8. AI 增强渲染 (ComfyUI + InvokeAI)

#### ComfyUI 展厅工作流
```
1. 输入: 展厅平面图 (Inkscape 导出 SVG → PNG)
2. ControlNet Depth: 空间深度控制
3. ControlNet Canny: 边缘控制
4. IP-Adapter: 风格参考
5. KSampler: SDXL / FLUX 生成
6. Upscale: 4K 放大
7. 输出: 展厅效果图
```

#### 推荐模型
- SDXL: Juggernaut XL, RealVisXL
- FLUX: dev/schnell (需 16GB+ VRAM)
- 展厅专用 LoRA: Interior Design, Architecture

## 输出
