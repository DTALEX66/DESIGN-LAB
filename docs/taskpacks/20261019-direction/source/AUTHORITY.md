# DESIGN-LAB 权威定位（建议纳入正式 Authority）

## 身份
中文：设计实验室。英文：Visual Design Lab。项目身份：DESIGN-LAB / design-lab。

## 正式定义
DESIGN-LAB 是面向职业视觉设计的 AI 原生、平台中立的专业视觉智能与可复用设计能力系统。它将视觉知识、审美方法、参考图理解、提示词生成与反推、设计软件自动化和经过验证的专业经验，转化为可检索、可组合、可测试、可版本化、可部署的能力，并将经用户或获授权 Agent 验收的知识候选提交 AAOS 正式审核。

## 产品本体
视觉智能 + 审美能力工程化 + 设计能力库 + 设计软件自动化 + 受控知识回流。不是画布、通用编辑器或全流程设计文件交付平台。

## 六大能力域
1. Visual Intelligence。
2. Aesthetic Analysis。
3. Prompt Intelligence。
4. Design Capability Library。
5. Creative Tool Automation。
6. Knowledge Candidate & Evaluation。

## 模型与工具
支持本地、云端及混合模型，按任务基准、视觉能力、隐私、成本、延迟和可靠性路由。支持 API/SDK、原生插件、MCP、脚本/CLI 与受控 UI 自动化。所有模型和适配器均需真实任务验证、读回和失败边界说明。

## WORK-LAB 边界
WORK-LAB 负责通用工作流、全局配置、权限/预算、跨项目协调、运行监测、维护和通用回执。DESIGN-LAB 负责专业视觉智能、审美方法、提示词能力、设计能力 Registry 和专业评价。通过版本化接口协作，不直接写入对方私有数据库。

## AAOS 边界
AAOS 负责正式知识、来源/证据治理、审核与长期学习。DESIGN-LAB 保留设计运行所需的本地能力注册和专业方法，但只向 AAOS 提交候选；AAOS 的接收与验证状态必须由 AAOS 返回。

## 永久非目标
不建设第二套画布/编辑器；不以完整设计文件制作交付为产品本体；不成为通用 Agent Runtime、聊天客户端、模型网关或跨项目调度器；不取代 WORK-LAB 的通用治理和 AAOS 的正式知识真源；不将未经许可和测试的热门资源直接视为合格能力。
