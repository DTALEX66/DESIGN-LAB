# DESIGN-LAB 桌面设计规则（提案，未实机批准）

## 氛围与信息层级

日常工具密度约 4/10，布局稳定，动效强度约 1/10。内容优先，适度留白；不做营销 Hero、无限动画、异形布局或模型控制驾驶舱。主任务输入与结果是中心，三主导航稳定。

## 色彩与玻璃

珍珠白背景 #F4F6F8；实底内容 #FFFFFF；正文 #17212B；次级 #566472；边界 #D8DFE5；强调 #356B92。炭黑备选 #111820 / #1A232D，正文 #EEF2F5。状态采用文字+图标，不依赖单色。玻璃只用于导航与临时面板，模糊层数量尽量少，低性能或系统关闭透明时回退实底。真实桌面穿透不是本设计默认已实现能力。

## 字体与组件

Segoe UI Variable/Segoe UI/Microsoft YaHei/系统无衬线。正文14–16px，元数据至少12px。按钮清楚写“整理方案/保存修订/复制材料/下载”，不使用“启动智能体”。控件高度约36–40px，键盘焦点可见，标签放输入上方；错误紧邻字段。圆角输入/按钮6–10px、临时面板12–16px；不统一巨型圆角卡片。

## 布局与页面

桌面范围1280×800至1920×1080；125%/150%缩放可用。主要工作区最多两列，详情按需打开。设置、来源、版本、JSON和日志后置。三主导航：设计辅助/知识与提示词库/我的方案。没有手机端，没有第二套 Agent/剪辑器/画布。

## 运动与性能

仅必要的120–180ms opacity/transform 过渡；减少动态效果时移除。无持续循环、自动播放和浮动装饰。分页/窗口化列表、缩略图、按需模块，不把后台解析塞主线程。初始只请求当前页面必要数据。

## 状态与文案

分别显示已保存、方案已提供、用户选用、外部未验证；不把模型可选画成已经调用。试用复制不要求先审批。文案以用户任务为主，Source/Schema/Hash/Provider 等术语放详情并解释。示例数据明确标识。AAOS 未来互联无当前主页入口。

## 技能适配说明

参考 Stitch 设计规范技能的颜色、层级、组件与反通用模板原则；按用户要求覆盖其持续动效、移动端、营销 Hero 和字体限制等默认建议。本项目优先轻量桌面、系统字体、稳定正文与低动效。
