# 交接场景示例（人为编写的规划材料，未执行生成）

## 一：产品品牌与宣传片，含3D白模和粒子

输入：一个桌面工具即将进入宣传期，希望清晰、克制地表达“更快找到需要的方法”。示例不是对任何已审计产品能力的真实宣传声明。

共享约束：珍珠白/炭黑背景、单一品牌强调色、真实界面文字由后期叠加、产品轮廓保持。输出包：UI/VI/UX方向说明、海报/封面物料清单、15秒宣传片分镜与声音要求、目标工具交接。

| 镜号 | 时长 | 画面与目的 | 相机/运动 | 声音 | 外部制作约束 |
|---|---|---|---|---|---|
| 01 | 5秒 | 简化白模桌面物体建立空间 | 缓慢推进，主体稳定 | 轻环境声渐入 | 3D软件出预演，焦段/单位随工程说明，不在DL运行 |
| 02 | 5秒 | 粒子从分散到有序，表达归纳 | 相机基本稳定，粒子运动承担变化 | 单次清楚的聚合音效 | 精确粒子路径外部仿真；生成模型仅补视觉，不承诺粒子计数 |
| 03 | 5秒 | 产品展示与品牌结尾 | 镜头减速定格 | 音乐收束，旁白可选 | Logo与UI真实文字在外部后期保证 |

给外部Agent：建立简化几何和相机预演，明确单位/帧率/画幅，导出分镜关键帧和预演视频；不修改原始产品工程。给媒体模型：参考A控制产品外形，参考B控制镜头运动，参考C控制材质风格；分别写保留与可变化内容。若目标入口不收视频参考，退回关键帧或换已验证入口。DL当前仅导出这些材料。

## 二：原创小说片段转漫剧/短剧方案

输入范围：用户提供的一段原创故事“雨夜车站，两人因错拿笔记本相遇”。仅分析已给段落，不宣称读过全书。

方案：人物A急促但克制；人物B冷静；场景是同一站台，同一雨势与服装。先给用户两个方向：二维漫画叙事或实拍感短剧，各自说明制作复杂度和需要的参考。角色手册/场景手册与镜头版本分开。

三镜草案：站台远景交代关系 → 笔记本特写形成误会 → 双人中景对白揭示线索。对白文本、人物视线、屏幕方向、镜头顺序和环境声明确。选择模型后再根据其时长、角色参考和原生音频支持拆分；不预先承诺长篇多集身份完全一致。连续性问题可手动反馈并修订手册。

## 三：说唱/MV与独立音频方案

输入：用户自己的16小节歌词，示例节拍90BPM、4/4。节拍数值是任务假设，不是实际音轨测量。

设计：按前奏/主歌/副歌/收尾组织，不强迫每一句都切镜。声音方案列演唱方式、语速与重音、伴奏密度和混音空间；画面方案列角色/地点/动作/节拍点与粒子或2D图形用途。音乐、配音、音效分别给目标模板，不一段词通吃。

算术：90BPM时每拍2/3秒，一小节8/3秒，16小节128/3秒；最后以实际音轨与外部剪辑工程为准。逐拍精准同步通过外部剪辑，不承诺生成视频自动对齐。用户可只使用音乐建议或只复制镜头脚本，无需启动其他项目。
