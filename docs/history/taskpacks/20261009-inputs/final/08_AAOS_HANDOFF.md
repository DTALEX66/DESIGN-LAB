# 交给 AAOS ArcheAxis 的提示词

请把以下作为 AAOS 与 DESIGN-LAB、WORK-LAB 的最新长期协作要求，与本项目当前蓝图、知识模型、人类/AI学习侧、前端与公共合同对账。不要因尚未实现取消目标，也不要把规划标已完成。请在本项目已授权范围完成必要定义/接口/前端/验证工作，而不是只追加报告。

三个项目是知识、实践、设计生产与学习反馈的互补体系。AAOS 是长期知识、来源、版本、关系、研究与 Human–AI 学习的共同基础，不是总控制器；WORK-LAB应用编程/AI/自动化/治理知识并发现和复现真实经验，不只是调度器；DESIGN-LAB是全品类设计知识应用和专业自动化系统，保留设计判断、能力配方、软件适配、有界执行与核验，生产由现成软件完成。DL不是单纯素材库、美工、课程工具或新通用编辑器。

AAOS人类学习侧按目标、前置、常见误解和知识精确版本提出教学需求，由DL共同设计表达并制作图解、动画、演示、练习或课件；AAOS登记课程/版本/知识关联、实际呈现、练习、长期学习状态和评价。编程/AI/治理案例由WL提供获准真实材料与技术复现。反馈按知识/技术、表达/教学、运行/集成回正确责任方，并形成一轮可追踪修订。

允许DL/WL提交知识候选、观察、失败、反例和纠正；候选保存、专业核验、教学使用与自动执行资格分别判断。日志、一次成功、模型自评、偏好不自动成为通用知识，同源文章/动画/课件不是多份独立证据，视频播放完成不代表掌握。

优先复用现有对象/接口，实现最小知识读取与版本引用、候选提交与幂等回执/变更、教学需求、内容交付、学习反馈。教学需求含人群/前置/目标/来源版本/误解/约束/反馈；成果包括按需内容、源工程引用、文本、字幕及必要视觉描述、练习规则、知识映射、依赖与限制。源工程/制作配方由DL维护，AAOS管理知识及课程/学习状态；不用复制所有大型工程进两仓。

AAOS离线时允许适合用途的授权固定快照，各方独立恢复；未知权利、撤销与要求新鲜检查的情形不能伪装通过。在途任务知识固定，新revision用于下一次或明确重算。各方业务DB独立，不合并三仓，不迁移客户/私人会话/凭证/未授权资产，教学代码不继承桌面执行权限。

同步审查前端是否能表达需求、接收内容、练习和反馈，而非只统计点击/播放。同步当前权威定义、机器配置、Agent入口、任务、生成器、测试与部署投影；历史原件保全并解除执行效力；别创建第二权威链或重置已完成账本。本包只提供协作要求，AAOS既有完整学习蓝图不因本示范缩窄。
