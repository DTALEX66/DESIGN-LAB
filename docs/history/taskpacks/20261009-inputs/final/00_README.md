本包把本轮已找回的闭环审计、联合蓝图、自动化深化、综合路线裁决与随后提供的前端和执行依据迁移要求合并。核心动作是：校正产品定义与执行依据，修复真实闭环断点，迁移前端主任务流，接入版本化知识及三方教学反馈。

## 直接使用

1. 在 DESIGN-LAB 当前真实仓库中打开 Codex，把 `02_CODEX_EXECUTION.md` 全文交给它，并提供本包目录。
2. 执行者先读 `01_MASTER_TASKPACK.md`，复核本地与远端增量，然后把 `03_TASKS.json` 映射到仓库既有唯一任务账本。此 JSON 是待映射的交接清单，不是新建的运行主账本。
3. 按任务依赖执行，依据 `04_ACCEPTANCE.md` 验收。定义、代码、接口、生成来源、测试和部署投影同步处理。
4. 将 `08_AAOS_HANDOFF.md`、`09_WORK-LAB_HANDOFF.md` 分别交给相应项目。各自维护自己的仓库与状态，不由 DESIGN-LAB 越仓接管。
