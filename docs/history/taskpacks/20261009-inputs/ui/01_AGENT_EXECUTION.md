## 必须理解的产品定义

DESIGN-LAB 是全品类专业能力资产、设计知识应用与自动化系统：理解文字、截图、多图、文件、音视频需求，引用设计规范、方法、风格和经验，生成目标包、制作方案、原生操作计划与实际产物，独立核验结果。专业范围包含品牌、平面、字体、出版、包装、空间、UI、三维、动效、视频、声音、游戏视觉与教学表达；实际覆盖分别声明，不能让六张示例卡把范围锁死。

前端以能力资产、分析与制作、成果与反馈为本批主结构。辅助连接、日志与诊断按需展开。不要恢复以项目工作台、KPI、看板和审批大厅为中心的路线。任务、集合、版本、恢复记录与项目标识仍可复用。

AAOS 管长期知识主版本、课程登记、练习与学习状态；DESIGN-LAB 管专业判断、能力包、软件适配、源工程、教学生产及修订；WORK-LAB 管工作实践、执行证据与技术复现，可按需提供运行支持。教学需求进入同一制作体系，不复制教育后台；各自独立恢复，不共享业务数据库，不默认绕行三方。

## 如何使用效果图和素材

按 `specs/screen_map.json` 的对应页面实施，保留布局、信息层级、冷蓝/银白风格及组件状态。先复用现有品牌，再对齐本包；不因追求文件名一致搬目录或换技术栈。

先使用 SVG，再用独立 PNG；整页截图只作视觉基线。`slice_map.json` 的坐标是 1920 × 1080 CSS 坐标，4K裁切乘 2。不得把文字和按钮切成图。卡片图可换用户真实案例，必须同时更新 manifest、引用与许可状态。

无法使用素材时按 `03_ASSET_USE_AND_GENERATION.md` 的单资产提示词重建，只生成背景/装饰，准确文案由原生文本排版。截图仅能指导视觉，不能证明 PSD 图层、AI 路径、三维场景或时间轴存在。

本原型的虚构 ID、硬编码卡片和 localStorage 草稿只用于参考。生产必须读真实 API，做加载/空/未知/离线/失败/权限/冲突/恢复状态；不能直接复制演示数据作为“接入完成”。`UI_DATA_CONTRACT.json` 是语义提案，先映射已存在对象与接口，不创建同义 Schema 或猜测新 URL。
