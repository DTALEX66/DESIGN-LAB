## 视觉核对

采用同一视口、字体和输入版本对照本包效果图。首先核对结构、层级、行长、关键操作及状态含义，再核对间距、边框、字体与媒体位置。CSS源码和变量是实现依据；截图中的虚构数据、字段值、菜单数量不应被永久硬编码。

建议同环境几何偏差控制在 2–4 CSS px、基准字号一致；如正式字体或现有品牌资产改变，先记录差量再更新视觉基线，不能机械用全屏像素百分比判业务合格。关键中文不能截断，禁用动作说明要能看见。

长页要检查完整滚动内容，不能只核对首屏。视觉快照只证明画面，不证明权限、宿主结构、真人签名或跨项目接入。
