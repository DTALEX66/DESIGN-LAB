# 素材使用、切片与再生成

## 先使用现有文件

1. 生产先检索仓库与用户指定 UI 套件的品牌、组件与图标。未访问的本机目录在报告中说明，不能宣称已核对。
2. 本包 `assets/art/*.svg` 为可直接使用的矢量示例，原生画布 960 × 600，浏览器渲染版 `_4k.png` 为 3840 × 2400。SVG 放大不需要 AI 重画。
3. `screens/4k/` 是整页视觉基线；用于核对布局和对齐。长页 `_full.png` 展示完整滚动内容，首屏 `_3840x2160.png` 展示固定视口。
4. `slice_map.json` 记录 1920 × 1080 CSS 坐标。4K图裁切需要乘 2；长页使用页面坐标和实际尺寸核对。不要从窄屏与深浅主题互相借用坐标。
5. 卡片图从独立 SVG 或 PNG 取；不要从整页图里截取低分辨率卡片图再放大。SVG 文字是插图自身的图形说明，页面正文仍用可编辑文本。

## 可切片与应重建的边界

可用作媒体：主视觉、能力示例、教学图解、真实产物预览。应重建为组件：导航、搜索、文字、按钮、徽章、表单、表格、进度条、提示、评审、可变计数及所有交互区域。不能整页背景叠透明热区伪装应用，也不能把状态文案烘焙进装饰图。

## 文件失效时的精准再生成

优先重跑 `scripts/build_art.py` 再以浏览器渲染矢量；不需要重新生成 UI 图。如果确实只能用图像模型，每次只生成一个媒体资产，引用对应本包图像，并采用下面的基础提示词和专用差量。

**通用基础提示词：**

> 以所附单张素材为参考重建一张 8:5 设计插图，用于 DESIGN-LAB 专业应用中的内容缩略图。保持冷蓝、银白、深海军蓝的统一色彩，简洁清晰的形体、准确的主体位置、留白与层级；只画插图，不画软件窗口、按钮、菜单、状态徽章或整页界面。不要添加品牌 LOGO、乱码或新文案。需要准确文字时留出对应排版区，由前端或创意软件原生排字。输出至少 3840 × 2400 的真正清晰图像，实际输出像素不足时先说明，再选可验证的放大方法；不能把请求尺寸当成实际尺寸。

| 资产 | 专用差量 |
|---|---|

| brand-poster | 浅冷灰背景中的深蓝竖版海报，环形几何居中，标题与辅助文案区保留原位置 |

| packaging | 两个蓝色长方体纸盒，保持当前等轴透视、相互位置与尺寸关系；不生成未知刀模 |

## 导入与许可

本包新绘插图与页面源用于本任务部署参考。用户原品牌图只用于其品牌上下文；不把它或未知来源内容自动作为开放许可素材分发。字体声明与许可证随包保留，生产可以优先使用用户已有 Segoe UI / Inter / 已获准中文字体。所有新替换图记录来源、生成/修改方式、尺寸、用途、许可与 hash；不能删除来源身份。
