# 交互、组件与状态

## 核心路径

能力搜索与详情 → 带入能力/知识版本 → 输入与交付目标 → 分析纠正 → 目标生成包/原生计划 → 执行与观察 → 产物核验 → 版本改稿/真人评审/交付 → 反馈与候选回执。用户只要分析时可以在分析结束；无需强制全部阶段。

教学需求带入学习目标与知识版本后走同一制作链。表达修订回 DESIGN-LAB，知识/技术核验由 AAOS 与专业来源处理，运行问题回实际模块。多方问题允许联合负责人，不能用类别按钮自动证明知识错了。

| 组件 | 必须行为 | 异常/负向规则 |
|---|---|---|
| CapabilityCard / FacetFilter | 展示用途、示例、分类轴、范围；搜索组合筛选；结果可带入输入 | 权限过滤发生在标题、缩略图、计数之前；未知资格不显示可执行 |
| InputComposer / ReferenceRole | 文本、上传、参考职责、目标与强约束；本次输入草稿可恢复 | 类型/大小由服务能力声明；解析失败不清空有效输入；不偷偷上传外部 |
| KnowledgeRef / EvidenceDisclosure | 主视图给关键限制，展开来源/版本/证据 | 撤销立即阻止受影响用途；快照不是知识主写入源 |
| AnalysisCorrection / DirectionChoice | 查看推断并纠正；保持方法/偏好分离；接续已有对象 | 纠正本次输入生成新 revision；不静默升级为通用规范 |
| TargetPackage / ExecutionRoute | 真实工具参数、强约束、输出与检查；可选择降级/交接 | 不支持锁定时明确损失；人工交接不冒充自动执行 |
| RunControl / RecoveryOptions | 后端状态驱动暂停、取消、预算截止、对账恢复 | 指令返回成功不算完成；租约冲突不得抢占；超时先读回 |
| ArtifactViewer / PatchComposer | 实际格式、版本、可继续修改；局部范围与稳定对象引用 | PNG不标PSD；改稿生成新版本；保留未改对象与旧证据 |
| VersionCompare / JuryForm | 精确产物版本与hash，真人决定、意见、真实回执 | Agent不代签；没有回执显示草稿；新版本旧接受不沿用 |
| DeliveryChecklist | 按交付目标计算权利/审美/原生/预检/依赖；测试导出可用 | 资格缺失不生成正式合格；无需原生工程不强加PSD检查 |
| FeedbackDraft / Receipt | 版本、场景、观察、许可、用途、责任；幂等回执可查 | 候选受理不是批准；未允许出域的材料不进待发队列 |
| TeachingRequest / ContentPackage | 学习目标先于形式；字幕、视觉说明、练习规则与源工程 | 动画不冒仿真；播放不冒掌握；H5P未实测不称兼容 |

## 所有数据页的状态合同

| 状态 | 展示与恢复 | 数据约束 |
|---|---|---|
| loading | 保留合理布局、显示正在读取；减少动态模式静态骨架 | 不闪现上一个用户的内容 |
| empty | 描述无记录或无匹配，清除筛选/新建任务 | 不能暗示未来功能已可用 |
| unknown | 解释缺哪项证据，允许合法的分析或交接 | 不把 null 转成通过或不合格 |
| offline | 给快照版本、用途、新鲜度和受影响动作 | 在途任务版本固定；撤销/需在线复核项不可继续 |
| forbidden | 返回可用内容；只有实际用户流程允许时提示请求权限 | 标题、缩略图、计数、引用和摘要都不泄露 |
| timeout / uncertain | 保留已确认结果，核对宿主、文档与动作回执 | 不盲目重跑创建、导出或付费操作 |
| conflict | 显示基准/当前版本差分，更新后再提交 | 同幂等键不同内容冲突；不覆盖他人修改 |
| cancelled | 标未完成检查，提供材料/恢复或新任务 | 不回写已完成，不丢旧证据 |
| queued | 本地草稿/获准待发/已受理/核验各自显示 | 仅获准摘要可发送，重试不重复提交 |
| error | 简洁原因、保留输入、重试/替代；日志按需展开 | 不把堆栈、凭证或私人内容显示在主流程 |

## 人机与视觉行为

桌面导航 232 px；内容边距 40 px（紧凑尺寸 26 px）。卡片随可用宽度由三列/两列/一列重排。窄屏底部导航只负责核心入口；筛选可局部横向滚动，页面本身不得横向溢出。长表格有明确滚动容器。移动端优先检索、起草、查看和反馈，不绕过宿主占用或后端权限。

生产表单使用可读 label、错误说明与 aria-describedby；异步结果使用 aria-live，键盘焦点可见。加载和错误不能重置编辑内容。关键控件触控目标至少 44 CSS px；被禁用动作旁说明原因，并提供可行下一步。不能依赖颜色区分资格。

如宿主或画面包含客户材料，预览/日志/错误/缩略图同样需要权限过滤。截图是否可保留也按该产物的用途与许可判断。

## 参考原型的交互范围

导航、搜索领域筛选、能力层级演示筛选、文件名选择、主题切换、演示包下载、演示暂停取消、本地纠正/改稿/评审/反馈草稿可用。localStorage 内容只代表当前浏览器演示草稿；不跨项目发送、不生成真回执。其余动作明确提示接入点，不用假数据返回成功。

执行暂停、取消、恢复和评审仅演示交互，生产必须由真实服务确认。此原型没有包含病毒扫描、认证或文件解析实现，不应部署为真实生产后端。
