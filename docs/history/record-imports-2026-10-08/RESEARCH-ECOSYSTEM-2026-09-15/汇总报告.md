# 前沿研究与产品生态｜两轮监控汇总

**ArcheAxis · WORK-LAB · DESIGN-LAB｜2026-09-15**

本包针对当前会话前两轮监控做去重与事实复核，不是全网完整巡检，也不是远端仓库审计。11 个候选全部来自历史监控，本次新增的是可追溯来源、版本差分、必要更正与验收方案。所有评分均为本次适配判断，不代表官方榜单或实际测得的收益。

## 一、重大变化

**高｜把“值得研究”与“可以接入”分开。** 上一轮最需要纠正的是 GRACE：论文确有方法与代码链接，但本次作者仓库为空，无法交付可复用实现或核验代码许可。它从“立即代码验证”降为“方法保留、实现待发布”，不作为 ArcheAxis 当前底座。来源：S01、S02。

**高｜WORK-LAB 不凭一篇论文整体重构。** Live Trace Model 的作者同时报告了暂存笔记方案达到相同准确率且更便宜，且描述了顺序敏感任务边界。确定性状态的审计价值值得验证，但要和现有机制、简单暂存笔记比较，再决定最小吸收。来源：S06—S08。

**高｜修正 NeoMME 的实际验证对象。** 应选择 `Hcompany/NeoMME-260M-Retriever` 或对应检索权重，而非把基础 `NeoMME-260M` 当成完整检索系统。约 255 倍压缩针对特定嵌入表示，不是原始资料加索引的总空间；硬件收益尚未在用户设备实测。来源：S09—S12。

**高｜AG-UI 不能继续笼统写“无需关注迁移”。** 9 月 10—11 日若干中间件及 Strands 集成明确存在破坏性变更。是否影响用户项目取决于实际锁文件与调用路径，本包仅要求条件性核查，不制造未经验证的紧急漏洞报警。来源：S17。

**中｜去掉旧事重报和成本承诺。** Penpot 旧 MCP 仓库归档迁移是 2026 年 2 月事件，不是 9 月新迁移。Figma 的 22.5% 是官方客户案例结果，不能承诺 DESIGN-LAB 同等降本。来源：S20、S22。

## 二、ArcheAxis 候选

|候选|优先级|本次相对历史的变化|复用方式|结论|
|---|---|---|---|---|
|NeoMME-Retriever|高|明确检索权重、压缩口径与本机性能未知|提供方、适配器|首批对照验证，不替换所有 OCR|
|RefVerifier|高|补入开放全文覆盖和小样本端到端限制|算法供体、适配器|先验证引用链与证据片段|
|CLAIM-CAL|中|材料有入口，但未完成可执行产物与许可核验|算法供体、仅供参考|材料先行；校准不等于事实核验|
|GRACE|观察|作者仓库当前为空|算法供体、仅供参考|暂停代码接入，不阻塞其他工作|

RefVerifier 的主张检测 F1 为 0.990、摘要定位命中 98%，都不是端到端事实核验正确率。论文还报告开放全文解析覆盖 57.6%，8 篇稿件端到端判定准确率 71%。本包要求“来源可得率—定位—判定”分阶段测量，无法获取原文就明确无法判定。来源：S03、S04。

建议保持两条可协作的路径：文本资料继续原摄取/检索链；扫描件与复杂页面可先视觉召回，再按需精解析。两条路径都必须回到原始资料、版本和页/段/坐标，不把页面检索得分当事实可信度。该架构是本包建议，不是已完成实现。

**人类学习与机器学习两侧不能被缩减。** 本次候选偏向检索与证据，未补足 FSRS、知识追踪、复述教学、记忆宫殿、多模态教学等完整新研究。包内保留这些覆盖缺口及下一轮队列，不把“没有完成覆盖”写成“已查过且没有重要更新”。新增 AX-R05 的作用是保护现有闭环，不是没有证据就研发一个新教学平台。

## 三、WORK-LAB 候选

|候选|优先级|本次差分|复用方式|结论|
|---|---|---|---|---|
|tracelab / Live Trace Model|高|补入廉价暂存笔记基线与失败边界|算法供体、适配器|四组验证，禁止先定重构结论|
|GitHub Agentic Workflows|高|明确只读外部状态与隔离工作区写入的不同|提供方、算法供体、仅供参考|优先吸收治理测试，不替代 WORK-LAB|
|codex-acp / ACP|高|v1.11.0 是实现版本，不是通用会话联邦完成|适配器|逐运行时列能力和损失|
|AG-UI|高|补入具体子包破坏性变更|适配器|锁文件与调用路径先行|
|Deep Agents Code|中|补入 0.1.69 的凭据/配置来源/嵌套用量差分|算法供体、仅供参考|吸收回归测试，不迁移整个框架|

GitHub Agentic Workflows 的 MIT 代码与安全输出模式值得阅读，但云端运行仍可能产生 Actions 和模型费用；外部状态写入的隔离不意味着执行器连本地补丁都不能产生。工作区、外部写入、凭据与审批范围要分开定义。来源：S13—S15。

本项目最优先的是把真实缺陷变成可验证门禁：运行事件、权限上下文、恢复、并发、幂等、用量和成本。已有模块优先补测，缺少证据不宣布缺陷已被修复。Radar 归 WORK-LAB，但它只保存发现、来源、版本、评估、趋势、候选和验证状态；不得复制 ArcheAxis 的知识或 DESIGN-LAB 的资产真值。依据：U02、U03。

## 四、DESIGN-LAB 候选

|候选|优先级|本次差分|复用方式|结论|
|---|---|---|---|---|
|Penpot / Penpot MCP|高|保留 2.18；归档迁移旧事去重；补聚焦页面误写检查|提供方、适配器|本地单用户先读后写，副本中保存重开|
|Figma MCP / Code Connect|中|22.5% 仅为案例；权限和导出能力需按账户确认|提供方、适配器|已有权限时可选对照，不能成为唯一底座|

Penpot 官方 MCP 文档涉及活动标签页中聚焦的页面，因此执行前需要核对文件、页面和对象目标，不能只说“当前打开了设计文件”。旧 MCP 仓库已经归档，安装应重新依据当前官方主仓库与帮助。来源：S20、S21。

本包对“可编辑”的要求是对象语义、保存重开、继续修改和恢复，而不是只看扩展名。原生 Penpot、PSD、AI、Blender 场景等与交换文件、栅格预览分别记录。SVG 可能丢失文本/组件语义；OTIO 或 glTF 也不能自动证明所有宿主特性无损保留，必须列损失矩阵。PNG/MP4 继续可作有效素材和预览，但不替代约定的原生生产资产。来源与范围依据：S25、S29、S30、U01、U03；具体验收为本包设计。

图像、视频、音频、3D、Adobe 自动化、Blender、ComfyUI 等继续在范围内，但本轮不编造新候选，也不凭监控频率强行增加接入工作。

## 六、建议进入概念验证的项目

**第一批只保留三个主验证方向**，可以按各项目准备情况独立推进，不同时购买服务或拉取一堆模型。

|优先级|方向|任务|主要对照|未通过怎么办|
|---|---|---|---|---|
|高|NeoMME-Retriever|AX-R01 → AX-R02|现有文本链、视觉召回、混合链|保留现有检索，记录失败或收益边界|
|高|运行状态治理|WL-R03|现有机制、暂存笔记、轻量状态、tracelab|选择更简单便宜的方案，不强制引入论文实现|
|高|Penpot 原生编辑|DL-R01|只读核对、副本修改、保存重开与恢复|报告对象损失或权限问题，不以截图代替|

RefVerifier 的引用链可在现有解析能力上做有条件验证（AX-R03）。GitHub 治理和 AG-UI 先做只读兼容/安全对照（WL-R02、WL-R04）；不先部署云端。Figma 为可选对照（DL-R03）。GRACE 与 CLAIM-CAL 保留材料/许可门禁（AX-R04），不会阻塞前三项。

所有实验都必须冻结样本、版本、成本和失败分类；作者数字不能写进本项目结果。具体设计见 `03_执行与验收/概念验证与验收设计.md`。
