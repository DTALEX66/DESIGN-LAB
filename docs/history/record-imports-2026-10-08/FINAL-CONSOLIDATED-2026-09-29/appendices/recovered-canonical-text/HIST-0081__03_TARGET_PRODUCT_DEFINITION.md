# 目标产品定义 V3

## 一句话

**让 Open Design 和任意兼容 Agent 从“会生成设计”升级为“具备专业判断、视觉质感、生产约束和商业交付能力的 AI 设计团队”。**

## 核心价值

1. 把模糊 Brief 变成结构化、可验证的设计任务；
2. 把参考图变成原创设计 DNA，而非照搬；
3. 把风格和大师研究变成匿名、可组合、可追踪的方法；
4. 把审美判断变成领域化评分与证据；
5. 把设计结果变成可编辑、可生产、可交付的商业资产；
6. 用基线、回归和真实案例证明能力提升；
7. 保持 Open Design、Codex、Hermes、Figma/Adobe/3D 工具之间的可移植性。

## 非目标

- 不替代 Open Design 主应用和运行时；
- 不做“大师风格生成器”或受保护作品复制工具；
- 不用模板数量、人物数量或文档数量冒充能力；
- 不自动下载和执行任意第三方仓库、模型和权重；
- 不把 VLM 自评当作唯一质量证明；
- 不承诺所有设计领域一次性达到商业成熟。

## 成熟度目标

| 等级 | 定义 |
|---|---|
| L1 | 文件和规则存在 |
| L2 | Schema、Manifest 和静态验证通过 |
| L3 | Open Design/Agent 隔离任务成功 |
| L4 | 真实项目完成并经过独立评审 |
| L5 | 客户、开发或生产方实际验收 |

重点领域进入 Marketplace 或标记“商业可用”前至少达到 L4；标记“商业证明”必须达到 L5。
