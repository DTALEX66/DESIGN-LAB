# 风险登记

| 风险 | 严重度 | 控制 |
|---|---|---|
| 文档数量掩盖运行不可用 | P0 | 双轴证据模型、runtime registry、真实 task |
| Open Design 上游协议继续变化 | P0 | 现场 schema/--help、版本约束、compat tests |
| 大师研究变成直接模仿 | P0 | 匿名转译、禁止签名元素、原创性门禁 |
| 第三方 Skill Prompt 注入/越权 | P0 | quarantine、静态扫描、能力最小化、隔离运行 |
| 许可不明内容进入商业发行 | P0 | 来源 Registry、商业许可 gate、SBOM |
| AI 视觉评分自我循环 | P1 | 多 judge、确定性检查、人工设计师校准 |
| 视觉更好但生产不可落地 | P1 | 领域 preflight、可编辑交付、生产方反馈 |
| 风格/大师库大而浅 | P1 | 发现/验证/测试/商业四级，不以数量验收 |
| 产品/人物/食物图像假感 | P1 | 主体锁定、真实性 Rubric、负例集、精修回滚 |
| Overlay 覆盖现有成果 | P0 | plan 默认、staging、冲突语义合并、备份和 tree 回滚 |
| 多 Agent 同时写入 | P0 | 单 writer 锁、并发探测、checkout 隔离 |
| CI 用旧 SHA 或无关成功证明 | P0 | exact-SHA、workflow 名和 latest attempt 校验 |
| 模型/工具成本失控 | P2 | 分层 eval、预算和迭代上限、质量-成本 Pareto |
| 仓库被 minigame 样板主导 | P2 | example/fixture 边界、产品索引优先商业设计 |
