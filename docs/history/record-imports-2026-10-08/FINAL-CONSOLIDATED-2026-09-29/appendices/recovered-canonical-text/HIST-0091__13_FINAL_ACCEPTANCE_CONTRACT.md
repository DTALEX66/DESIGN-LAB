# 最终验收合同

只有以下条件全部满足，才能报告“V3 全量深化优化完成”：

1. V2/V2.1 Overlay 全部经过哈希与协议验证；
2. 所有 P0 缺口关闭；
3. 七个旧插件完成兼容升级并在运行时验证；
4. 商业路由、品牌 360 和视觉质量核心 Pipeline 完整运行；
5. 视觉质量总分模型、领域 Rubric 和 blocker 正常；
6. 风格谱系和大师方法有证据、匿名转译和非模仿门禁；
7. 至少品牌、平面、产品视觉、空间、UI 五个领域有真实案例；
8. no-skill / v1 / v3 对照证明重要领域质量提升；
9. 数字、印刷/包装、空间、动效/3D 和资产预检可用；
10. 交付包含可编辑源、预览、Manifest、BOM、provenance 和生产说明；
11. 来源、许可证、Skill 安全、secret 和依赖检查通过；
12. 本地 canonical gate 通过；
13. Open Design runtime E3 证据成立；
14. frozen exact tree 经独立只读 Codex reviewer GO；
15. worktree clean 或 frozen tree 明确等待用户授权；
16. 没有访问 E 盘、项目外写入、凭据读取或未授权发布。

如果未推送 GitHub，发布状态只能是 `READY_FOR_USER_APPROVAL`，不能声称 release verified。
