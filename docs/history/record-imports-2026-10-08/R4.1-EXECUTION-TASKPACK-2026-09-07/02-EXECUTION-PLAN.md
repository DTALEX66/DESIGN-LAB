# R4.1 执行计划

所有任务初始状态为 `NOT_STARTED`。已有 PR #115 成果仅为基线，不可改写为本包完成。任务中的“实机”指目标 Windows 软件真实读写并读取结果，不是静态扫描。

## A. 先收敛真相与运行边界

### DL-R4-001｜唯一状态账本与任务投影

**依赖：** 无。**解决：** 旧 job ledger、TASKPACK_PROGRESS、capability-status、机器盘点互相矛盾。  
**实施：** 创建 `tasks.json → task-result.json → verifier → current-status.json` 单向链；标识全部旧台账为历史或派生；将每个能力拆成结构、隔离运行、宿主运行、发布四个证据轴；为每个结果绑定 exact SHA、时间、软件版本和 hash。  
**验收：** 58 个旧任务和 T01—T18 都能映射到当前任务或明确历史承诺；不能再出现同一能力同时“runtime-pass”和“未装/待实机”；删改派生报告后可重生成相同结果。  
**回退：** 保留旧报告原文，仅回退生成器和新投影。

### DL-R4-002｜完成运行根、作品库与 `.hermes` 迁移

**依赖：** DL-R4-001。**解决：** 代码和活跃策略不一致，Git 忽略无法证明不越界写入。  
**实施：** 实现全局路径解析器，分别解析 `runtime_root`、`projects_root`、`model_cache_root`、`agent_profile` 及来源；扫描活跃配置、快捷方式、IDE tasks、脚本和宿主配置；记录真实写入 `.hermes` 的进程链；将数据按清单备份、hash、迁移，旧路径只读兼容。  
**验收：** Codex / DSH / Hermes（已安装者）、CLI、UI、Adobe 桥运行夹具后，项目运行数据只写新根；作品不会落在 Git；E 盘未触及；旧根无新增项目数据。  
**回退：** 使用迁移前 DB 和文件清单恢复；迁移期间禁止双写。

### DL-R4-003｜CI 触发、环境一致性与证据门

**依赖：** DL-R4-001。**解决：** PR / push 路径覆盖不完全、测试环境/浅克隆/临时数据导致结论漂移。  
**实施：** 让 PR 与 push 覆盖 `AGENTS.md`、`.project`、`integrations`、`packages/capabilities`、`src`、锁文件和新 `apps`；固定 renderer 下载 hash；独立每个测试临时根；把浅克隆证据不足报成明确状态；运行产物污染单独审计。  
**验收：** 仅改上述任一目录的 PR 必触发关键门；干净环境重复通过；错误环境给出准确诊断，不伪称源码失败或通过。  
**回退：** 不删门求绿，回退对应 workflow / bootstrap 变更。

## B. 修复产品基础语义

### DL-R4-004｜Operation、Attempt、取消与幂等

**依赖：** DL-R4-001。**实施：** request hash 绑定 idempotency key；异请求冲突拒绝；失败/未知可显式创建下一 attempt；`effect_not_started` 回到可安全重试而非成功；取消等待适配器确认并对账。  
**验收：** 修前复现的 4 类状态错误转为拒绝或正确状态；重启、丢回执、三次重试、取消竞态均无重复写。  
**回退：** 版本化 SQLite migration，保留所有旧 attempt。

### DL-R4-005｜资产版本、原子发布、可复现清单与单写锁

**依赖：** DL-R4-002、DL-R4-004。**实施：** 分离 artifact ID、版本 ID 和路径；版本与产物同一事务；失败 rollback；临时文件校验后原子发布；采用原子抢锁、租约及 fencing token。每次候选/交付生成不可变可复现清单：Brief hash、参考来源与 rights 决定、工作流 JSON hash、节点/模型 revision 与 hash、seed、输入/输出 hash、操作者、人工评审结论；不把凭据、私有会话或未经授权的原始内容写入共享记录。  
**验收：** 同名 `poster.psd` 连续保存三版成功；唯一键/I/O 失败不留下 ACTIVE 空版本；并发 writer 仅一方可发布；重启无悬挂引用；任一接受版本可从清单定位其生成/修改上下文。  
**回退：** DB/资产备份和待发布隔离区恢复。

### DL-R4-006｜真实 Profile、权限和 H3 决策

**依赖：** DL-R4-001。**实施：** Profile 依据格式、可编辑性、离线、已安装且可启动的软件、当前实测、用途条件和资源硬过滤；成本只在合格候选间评分；H3 单列用途、地域、许可版本、模型版本和资源阻塞。  
**验收：** `DENIED`、未安装、无宿主证据候选不能自动执行；个人研究不是对其他许可条件的豁免；H3 未清时只能产生拒绝记录。  
**回退：** 旧 profile 只读保留，不恢复误报路径。

### DL-R4-007｜Doctor 与模型就绪等级

**依赖：** DL-R4-002。**实施：** 区分 ABSENT、METADATA_ONLY、WEIGHTS_COMPLETE、LOAD_VERIFIED、INFERENCE_VERIFIED；验证分片/hash、符号链接、加载和短推理；校验工具退出码、版本和来源。  
**验收：** 空 snapshot / 仅 config / 仅 refs 不能 READY；OCR det+rec 都需识别，ASR 需真实转写，二者不能充当语音生成。  
**回退：** 探测只读；新下载临时校验后发布。

### DL-R4-008｜ComfyUI 与受控本地 MCP 创作闭环

**依赖：** DL-R4-004、DL-R4-005、DL-R4-007。**实施：** 以实际 REST/WebSocket 作为服务端真相源，支持实例连接、工作流发现、提交、进度、取消、失败恢复和输出收集；绑定 prompt/client/history/output。指纹含完整工作流图、节点和模型 hash；验证产物根、存在、媒体类型、hash；取消等待真实停止证据。纳入第一方本地 `comfy-mcp` 的可选 RuntimeAdapter，但只能连接任务中指定的本机实例，不能取代服务端审计链。模型下载、云端付费、批量执行、上传或外部传输必须有已记录的作用域授权；默认禁止。保留一条平面图/图像编辑 golden workflow 及成功、取消、失败恢复样例。  
**验收：** 图像生成、缓存命中、取消、断线重连各有实证；平面 golden workflow 连续 10 次均产生完整可复现记录；路径穿越和伪指纹被拒绝；未安装 Comfy 时 UI 诚实显示不可用；MCP beta 能力、版本与实际本机连接分别记录，不能只凭配置文件宣称已接通。  
**回退：** 固定可回退 workflow 与节点版本。

## C. 建成独立产品，再做 Adobe 真闭环

### DL-R4-009｜可安装 Python 服务

**依赖：** DL-R4-004—008。**实施：** 把 `src/design_lab` 变为可安装包和 CLI；以门面复用现有 reconstruction，不搬迁/重写全部算法；提供项目、导入、任务、事件、产物、取消、导出本地 API。  
**验收：** 非仓库目录可启动；重启后项目/任务可见；不依赖测试 `sys.path`；现有 CLI 兼容期可转发。  
**回退：** 切回旧门面，数据按 schema migration 回退。

### DL-R4-010｜TypeScript DESIGN-LAB 工作台

**依赖：** DL-R4-009。**实施：** 建 `apps/workbench`，最小页面含项目、导入、参考/预览、对象、任务、修改、导出、环境诊断；Codex/Hermes/DSH 通过同一 RuntimeAdapter 进入，单任务只选一个 runtime。  
**验收：** 用户无需 CLI 即能新建项目、导入、提交任务、看真实进度/取消/失败、刷新后恢复；拔掉 WORK-LAB/ArcheAxis 配置仍可用。  
**回退：** API 不变，UI 可独立回退。

### DL-R4-024｜受控宿主自动化后备层

**依赖：** DL-R4-002、DL-R4-004、DL-R4-009。**实施：** 将宿主控制顺序实现为强制 policy：官方 API/脚本 → UI Automation tree → 视觉鼠标/键盘。第一个 UIA 试点只允许读取状态、打开副本、导入和导出新文件；禁止自动覆盖源文件、发布、购买、上传。视觉后备需要人工确认、超时和审计日志。  
**验收：** 所有不在 allowlist 内的 UIA 动作被拒绝；输入副本/导出新文件均可追溯；人工未确认时视觉操作不执行。  
**回退：** 关闭 UIA/视觉 provider，不影响原生脚本路径或用户源文件。

### DL-R4-011｜Illustrator 稳定版真实控制

**依赖：** DL-R4-002、DL-R4-004、DL-R4-007、DL-R4-009、DL-R4-024。**实施：** 用固定案例比较 JSX 与候选桥，优先已装稳定版；实现文档定位、图层、路径、文字、位图、蒙版、AI/SVG/PNG 保存、关闭重开和读回；Beta MCP 仅资格赛。先用原生 DOM/脚本；只有该入口不可用时才走 DL-R4-024 的 UIA 后备。  
**验收：** 文本和路径可编辑，保存重开后再修改成功；不可误写用户无关文档；中断不重复建层。  
**回退：** 所有测试在副本/新工程执行，资产版本可恢复。

### DL-R4-012｜Photoshop 真实控制

**依赖：** DL-R4-002、DL-R4-004、DL-R4-007、DL-R4-009、DL-R4-024。**实施：** 替换 `NOT_EXECUTED`，比较 UXP 与一个候选桥；实现 modal、文件 token、文档定位、文本层/像素层/组/蒙版、PSD 保存、关闭重开和结构读回。先用 UXP/脚本；只有该入口不可用时才走 DL-R4-024 的 UIA 后备。  
**验收：** 至少文字、蒙版、独立图像对象可修改，重开后保留；失败不包装为成功；不覆盖用户原文档。  
**回退：** 卸载/回退本项目测试桥，工程恢复上一资产版本。

### DL-R4-013｜参考拆解和对象计划接入真实输入

**依赖：** DL-R4-006、DL-R4-007、DL-R4-009。**实施：** 接 OCR、区域、语义对象、层级与几何；记录置信度和可编辑边界；支持用户修正文字、字体、区域。  
**验收：** 三类真实参考生成对象计划并映射 AI/PSD；未知内容显式标推断，不编造成源图层。  
**回退：** 固定算法版本并保留原图和用户修正。

### DL-R4-014｜比较、人工 Jury、局部修改和可编辑验收

**依赖：** DL-R4-010—013。**实施：** 统一输出条件，展示叠加/差异/局部错误；对象 patch 只更新相关对象；视觉、结构、可编辑性分开计分。将 Human Jury 接入真实候选选择：Brief 符合度、构图、品牌、可落地性、rights 风险五项结论可追溯；模型评分只能辅助筛选，不能自动代替接受决定。  
**验收：** AI/PSD 各完成导入→制作→两次局部修改→保存→重开；每个接受版本均有人工选择/驳回记录；不靠整图贴底或文字转曲冒充成功。  
**回退：** 任意时刻恢复上一个接受资产版本。

### DL-R4-015｜M1 个人研究版发布

**依赖：** DL-R4-001—014 及 DL-R4-024（经宿主任务传递）。**实施：** 提供单一启动入口、升级备份、诊断、项目库说明和一套可复现案例。  
**验收：** 一份真实 Brief 能产出可复现候选、人工选定版本和可编辑交付包；非开发者可启动；前端与 AI/PSD 真工程闭环都通过；记录冷/热启动、案例耗时和已知限制；未完成视频、透明通道等媒体能力不混入“已发布”。  
**回退：** 应用回退不删除作品库。
