# Codex UI 统一验收清单

## 所有项目共同
- [ ] 先审计真实仓库，不以 Demo 替代正式实现。
- [ ] 正式页面已接现有路由/数据/API 或明确 Adapter。
- [ ] Loading / Empty / Error / Permission / Offline 状态齐全。
- [ ] Ctrl/Cmd+K、Esc、键盘 Focus 正常。
- [ ] Modal/Drawer 有 Focus Trap（框架支持时）。
- [ ] Reduced Motion 支持。
- [ ] Build / typecheck / lint / smoke tests 通过。
- [ ] 不在业务组件散落硬编码品牌色。
- [ ] 未跨项目串色、串 Logo、串术语。

## WORK-LAB
- [ ] Workflow Editor 可用且不破坏真实 Schema。
- [ ] Observer 明确只读。
- [ ] Approval/Audit 具备上下文与治理含义。
- [ ] 深黑蓝 + 电蓝/青，无橙金暖色。

## AAOS
- [ ] Evidence provenance 清楚。
- [ ] Capture→Evidence→Original/Learning→Memory→Review 可走通。
- [ ] AAOS 金色不是主交互色。
- [ ] AI推断与证据不混淆。
- [ ] FSRS 接真实算法/调度（若项目已有）。

## DESIGN-LAB
- [ ] Project Detail 是工作台，不是空卡片。
- [ ] Tool Adapter 显示安装/连接/路径/能力/权限。
- [ ] Preflight 能定位问题并分 Pass/Warning/Error。
- [ ] Deliverables 包含可编辑交付/Manifest/版本。
- [ ] 紫色不是系统主色。
