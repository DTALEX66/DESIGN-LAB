## Codex 读取优先级

开发时不要按“最老到最新”机械覆盖，而要按下面的权威优先级解决冲突：
1. **B10 最终版**：最终视觉、光效、交互、界面质感最高权威。
2. **B09**：真实交互行为参考。
3. **B08**：可运行 React/TypeScript 原型与可复用工程结构。
4. **B07**：路由、权限、状态机、组件契约、前端治理规范。
5. **B06**：完整交互态/异常态/响应式。
6. **B05**：页面信息架构和页面级内容。
7. **B04**：组件、Design Tokens、尺寸和状态逻辑。
8. **B03**：页面级母版；**AAOS 配色纠正包是 AAOS 色彩的重要权威**。
9. **B02/B01**：Logo/VI/图形语言/细节参考，只在不与后续批次冲突时采用。

### 强制视觉规则
- WORK-LAB：深黑/深海军蓝 + Electric Blue/Cyan；严禁暖橙、米金、杂志风。
- ArcheAxis/AAOS：深空黑蓝 + Ivory + Aurora Teal；星辉金只用于少量证据/关键节点强调，严禁金色主导、花哨宇宙海报化。
- DESIGN-LAB：黑/深灰 + 白 + Electric Blue；紫色可以出现在创意内容，不作为系统主色。
- 三个项目共享“组件/交互方法论”，不共享品牌皮肤；严禁把三套合并成同一套主题。
