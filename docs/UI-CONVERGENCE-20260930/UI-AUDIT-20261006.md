## 3. 已修复 —— 可操作性与无障碍

- **命令面板路由是坏的**：`'#' + view` 生成 `#dashboard`，而路由表匹配 `#/dashboard`，
  于是**每一条面板命令都落到错误页面**；在 `?dev=1` 下反而「看起来正常」，所以 dev 环境
  掩盖了它。面板是 ≤840px 下唯一的路由切换手段（B10 侧栏在该断点 `display:none`），
  因此这同时是移动端导航被阻断。现按 `ROUTE_VIEWS[].hash` 导航。
- 面板结果行从 `div+onclick` 改为真实 `<button>`（键盘可达），文案 `Open` → `打开`，
  并把搜索框与顶栏胶囊的「搜索页面 / 命令 / 资源」收窄为「搜索页面」（只有页面存在）。
- **焦点可见（2.4.7）**：`.input` 组与 `.palette input` 的 `outline:none` 移除；
  原先唯一的焦点提示是 12% alpha 的 box-shadow，在 `--surface-2` 上实测约 1.13:1；
  现统一用 `--color-secondary` 3px outline（实测 7.47:1）。`[role=button]`、
  `.table-wrap`、`#route-view` 补上焦点环。
- **减少动效（2.2.2）**：`prefers-reduced-motion` 块原本只关 transition，
  四类无限 keyframe 动画（ambient floatGlow、dashMove、pulse、scan-line）全部照跑，
  而且它 `box-shadow:none!important` 恰好抹掉了当时唯一的焦点提示。现覆盖
  `animation-duration/iteration-count`，不再动 box-shadow 以外的焦点，
  并在 `animateKpiCount` 内用 `matchMedia` 自行短路——文本补间对 CSS 不可见，
  原注释「CSS 层已处理」是错的，已改正。
- **对比度（1.4.3）**：白字压品牌蓝在 12–16px 全部不达标（按钮渐变两端实测
  3.92:1 / 3.13:1；状态药丸 1.83–3.35:1）。按实测改配：药丸文字改深墨 `--bg`
  并把 `.bad`/`.info` 渐变移到可达标的浅色端；主按钮/分段激活/legacy 按钮/阶段当前
  节点改用更深的同色系蓝（`#1D4FC4→#2A63D8`、`--accent-hover`）；
  小号强调文字（`.app-nav-brand`、`.brand small`）改 `--secondary`（7.88:1）。
  所有新配颜色对都用脚本算过并断言 ≥4.5（见 §5 命令）。
- 焦点管理：路由渲染会 `replaceChildren` 销毁用户刚聚焦的元素，导致每次换页焦点掉回
  `<body>`。`#route-view` 现在 `tabindex="-1"` 并在无键盘焦点时接管焦点；阶段跳转
  滚动后聚焦目标面板；面板关闭时把焦点还给调起者。
- 播报：`#route-view` 上的整体 `aria-live` 撤掉（它会让读屏在每次换页朗读整个 KPI 网格
  和表格，并与面板级 `role="status"` 双读），改为一条窄的 `role="status"` 状态行；
  同时修复「routed 视图里 `setStatus` 写进被隐藏的 `#status`」这一静默失败。
- 语义：侧栏 `div.nav[aria-label]` 改真 `<nav>`（role=generic 不支持可访问名，标签被丢弃）；
  表头补 `scope`，空的操作列表头改为有名字；项目名改 `<th scope="row">`。
- 跳转链接 `.skip-link`（2.4.1）放进 `<main>` 内、指向由 JS 创建的 `#content`
  （放 body 直下会先于 landmark 骨架而失效）。
- 表单标签：项目详情 12 个控件此前只有 placeholder（输入即消失，且必填/可选只写在
  placeholder 里）。新增 `fieldRow()` 生成真实 `<label class="field-label">`，
  规则全部 class 化——`label{}` 元素选择器正是 W02 清理掉的 B10 泄漏源。
- 关闭的抽屉不再停留在 Tab 序与读屏树里（`.drawer:not(.open)` 用 visibility 延迟切换）。
- 5 个 `.table-wrap` 横向滚动容器加 `tabindex=0 role=region`（Chromium 下不可聚焦的
  滚动容器无法用键盘横向滚动，操作列被裁掉时就是打不开）。
- 阶段状态标签不再 `aria-hidden="true"`——否则「PLANNED」只剩指针悬停 title 这一条通道。

## 4. 本轮同时修正了审计工具自己的两个缺陷（重要）

1. 初版探针把**隐藏的 `#workspace` 子树**也量了：`display:none` 只在祖先上，子元素自身
   computed display 并非 none，于是 715 条「键盘不可达」+ 大部分对比度失败都是幽灵元素。
   现在一律以 `getClientRects()` 是否产生布局框为准。
2. 修好药丸配色后探针反而报 180 条 1.06:1 失败：渐变在 `background-image` 里，
   `backgroundColor` 是 transparent，探针继续向上取到了药丸背后的深色面板。
   现在遇到渐变底判为**不可由 computed style 测量**，单独计数、不判通过也不判失败；
   渐变底文字的比值改由 style.css 里字面 stop 静态断言。

结论口径因此必须照实说：**「0 violations」只覆盖探针能真正测量的部分**。

## 5. 已修复 —— 安全（子代理发现，我自己复核后动手）

- `projectDetailId` 先校验后解码：`[^/?#]+` 允许 `%`，`%2f` 解码成 `/` 后会被拼进
  `/api/...` 路径；且裸 `%` 会让 `decodeURIComponent` 抛错打断整页渲染。
  现对**解码后**的值用 `/^[0-9a-f]{32}$/` 校验（服务侧是 `uuid4().hex`）并 try/catch。
- `openModal(title, bodyHtml)` 是全仓唯一以「传原始 HTML 字符串」为契约的接口
  （现无调用点，但它在浮层里，是未来最会被拿去做确认文案的那个）。改为接受
  `Node | string` 并用 `replaceChildren`。连同删掉的 sparkline，
  **发布产物 `build/main.js` 里 `innerHTML` 命中数 = 0**（此前有 1）。
- `api()` 现在在任何 401 上清掉会话令牌；此前只在首次连接失败时清，服务重启换新令牌后
  页面仍自认已连接，各视图把 401 文本当成数据渲染。
- 用户可见文案里去掉仓库内部路径与 Markdown 残留（`src/design_lab/runtime/job_store.py`、
  `findings/W06-TOKEN-WRITE-GAP.md`、`而**不**计入`）。
