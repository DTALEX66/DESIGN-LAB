# 本地工作台入口计划

目标：把已有项目、图像导入和任务历史服务变为可点击的真实工作台，不伪造宿主生成。
当前分支单写者执行，使用既有 Python HTTPServer、浏览器 DOM、TypeScript 源码；不引入云端服务。

- [x] 安全页面入口：固定 `/workbench`、`/workbench/main.js`、`/workbench/style.css` 白名单；页面无需 API 令牌，但仍校验 Host/Origin；API 保持 Bearer 校验。
- [x] 真实交互实现：会话令牌仅内存；新建/选择项目，PNG/JPEG 导入，服务器读回预览，任务/事件分页；显式加载、错误、重试与未接通状态。禁止 innerHTML 注入数据、浏览器存储令牌与外部资源。浏览器已覆盖主成功路径及刷新恢复，分页和异常交互尚非全面 UI 验收。
- [x] 入口验证：HTTP 测试先观察 401 失败后实现通过；源码/安装包 HTTP 测试各 17 项通过；浏览器实际操作单独记录。源码使用浏览器可直接执行的 TypeScript/JavaScript 公共子集，不进行转译；wheel 携带三项 UI 资源，不依赖开发目录。未执行 TypeScript 类型检查。

验收边界：本入口不是完整设计闭环；Adobe/Comfy 按钮仅在真实执行器接通后启用。启动令牌交付、完整安装入口和复杂参考图仍单独验收。
