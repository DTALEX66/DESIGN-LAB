> 本表是**建议的验收门槛**，不是已通过证据；实际采用与 rights 门由 GPT/用户决定。

## 验收维度（每个样例）

| 维度 | 通过条件 | 记录方式 |
|---|---|---|
| 文字准确 | 关键文字逐字正确；缺字/字体替代可见标注 | 文字清单 + 截图对照 |
| 对象层级 | 图层/对象分组合理且可独立选择 | 结构读回 JSON |
| 矢量路径 | 关键几何/字形为可编辑路径（非位图描边冒充） | 宿主对象检查 |
| 透明图层/蒙版 | 独立蒙版可改，透明保留 | PSD/AI 图层树 |
| 局部修改 | 改标题/换图/改色不重建锁定区域 | 前后版本记录 |
| 重开读回 | 保存→关闭→重开无丢失，可再编辑 | 宿主日志 |
| 视觉误差 | 与参考对齐的像素/结构偏差分级记录 | diff 指标（不唯一依赖 SSIM） |
| 人工判断 | 结构完整性、可编辑性、语义合理由人复核 | 人工记录 |

## 边界

- 页面可访问 ≠ 可下载/复刻/再发布权；所有候选 `rights_known=false`，采用前需 GPT rights 门。
- 不下载付费/受限素材；不开始复刻；不上传用户图。
- 同一作品的裁切不当作多样性（本表 11 个均为不同作品页）。
