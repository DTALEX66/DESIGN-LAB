# DLR-100 Jury Scoring Rubric

## Scoring Dimensions (1–10 each)

### 1. Visual Quality (Weight: 25%)
| Score | Criteria |
|---|---|
| 9–10 | Exceptional craft, pixel-perfect, cohesive system, exceeds industry standard |
| 7–8 | Professional quality, minor inconsistencies, meets industry standard |
| 5–6 | Competent but generic, visible rough edges, below industry standard |
| 3–4 | Amateurish, inconsistent, significant quality issues |
| 1–2 | Unusable, broken, or dangerously unprofessional |

### 2. Functional Quality (Weight: 25%)
| Score | Criteria |
|---|---|
| 9–10 | Flawless UX, accessible, performant, exceeds all success metrics |
| 7–8 | Functional, minor friction, meets success metrics |
| 5–6 | Functional but frustrating, misses some metrics |
| 3–4 | Partially broken, poor accessibility, misses most metrics |
| 1–2 | Non-functional or harmful to users |

### 3. Professionalism (Weight: 20%)
| Score | Criteria |
|---|---|
| 9–10 | Production-ready, documented, follows all best practices |
| 7–8 | Production-ready with minor documentation gaps |
| 5–6 | Needs polish before production, missing documentation |
| 3–4 | Prototype quality, significant rework needed |
| 1–2 | Concept only, not production-viable |

### 4. Rights Compliance (Weight: 15%)
| Score | Criteria |
|---|---|
| 9–10 | All assets properly licensed, documentation complete |
| 7–8 | All licensed, minor documentation gaps |
| 5–6 | Most licensed, some proof missing |
| 3–4 | Unclear licensing, potential legal risk |
| 1–2 | Unlicensed assets, legal liability |

### 5. Innovation (Weight: 15%)
| Score | Criteria |
|---|---|
| 9–10 | Breakthrough approach, sets new standard |
| 7–8 | Fresh perspective, clever solutions |
| 5–6 | Competent but derivative |
| 3–4 | Generic, no differentiation |
| 1–2 | Clichéd or regressive |

## Composite Score

```
Total = (Visual × 0.25) + (Functional × 0.25) + (Professionalism × 0.20) + (Rights × 0.15) + (Innovation × 0.15)
```

## Decision Thresholds

| Range | Decision |
|---|---|
| 8.0–10.0 | **ACCEPT** — Ship as-is |
| 6.5–7.9 | **ACCEPT with revisions** — Minor fixes, no re-jury |
| 5.0–6.4 | **REVISE + RE-JURY** — Significant rework needed |
| <5.0 | **REJECT** — Start over |

## Jury Composition

- 3 independent reviewers (blind to each other)
- 1 domain expert per case (brand, UI/UX, e-commerce, print, motion)
- Majority vote wins; split decisions go to lead reviewer

## Conflict Resolution

1. Reviewers score independently
2. Scores revealed, discrepancies >2 points discussed
3. Re-vote after discussion
4. Persistent split: lead reviewer decides
