# Frontend Acceptance Checklist

## Global
- [ ] Theme tokens loaded from CSS variables
- [ ] No hard-coded brand colors inside feature components
- [ ] Keyboard navigation complete
- [ ] Loading / empty / error / permission states implemented
- [ ] Mobile and tablet behavior verified
- [ ] Modal/Drawer focus trap verified
- [ ] Route-level code splitting enabled
- [ ] Tables support dense data and keyboard selection
- [ ] Graph canvases support zoom / fit / reset
- [ ] Destructive actions use confirmation
- [ ] Version and approval actions produce audit metadata

## Performance
- [ ] First route interactive target documented
- [ ] Large graphs virtualized or canvas-based
- [ ] Large tables virtualized
- [ ] Image assets lazy-loaded
- [ ] Non-critical panels deferred

## QA
- [ ] Visual regression snapshots
- [ ] Accessibility checks
- [ ] Empty-state snapshots
- [ ] Error-state snapshots
- [ ] Permission-state snapshots
