L6 三项目交互状态系统
========================
每项目 18 张 1920×1080 独立交互规范图：
基础交互、Hover/Tooltip、Focus/Keyboard、Expanded/Tree、Modal、Drawer、Context Menu、
Command Palette、Empty、Loading、Error/Offline、Permission、Approval、Version Compare、
Conflict Resolution、Notification Center、Tablet、Mobile。

统一规则，独立品牌人格：
WORK-LAB：控制 / 执行 / 可观测 / 审计
ArcheAxis：证据 / 记忆 / 学习 / 生长
DESIGN-LAB：设计 / 创作 / 校验 / 交付
