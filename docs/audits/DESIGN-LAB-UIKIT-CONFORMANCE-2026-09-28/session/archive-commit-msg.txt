Result recorded: deleting every unscoped element-only legacy rule through the CSSOM and
diffing all computed longhands of every .app element over all 12 routes + the default
and login screens (328 elements) leaves 0 legacy-supplied bindings inside .app (was 8,
fixed in #183) while 1923 remain OUTSIDE .app -- the login/connect screen, #workspace
and nav.app-nav are the legacy app. That is why the legacy element rules cannot be
blanket-scoped away; an earlier plan to do so would have broken those screens.

Placement and gate compliance
- docs/audits/, deliberately NOT docs/taskpacks/: docs/taskpacks/** is scanned by the
  authority-chain and context-integrity gates, so an archive there risks being
  misclassified as a historical taskpack or read as an authority claim.
- Archived .py/.mjs/.js carry SPDX-License-Identifier (License & secret hygiene gate);
  the 17 binary sheets carry .license sidecars for the same gate.
- All text files are valid UTF-8: the identity gate reads every tracked text file and
  fails CLOSED on an unreadable one. The first sweep output was written UTF-16LE by a
  PowerShell redirect and was caught by that gate; evidence is now written as explicit
  UTF-8.
