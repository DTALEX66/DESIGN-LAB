# USER_MODES_V42 — 五类用户与五种渐进模式

- 版本：`4.2`｜任务：`V42-0203`｜状态：`ACTIVE`｜证据：E1
- 依赖：V42-0201（唯一产品定义 V4.2）
- 机器可读：`design-lab/profiles/user-modes.json`（本文件的 SSOT 镜像）

## 原则

同一能力引擎提供不同披露与控制强度，**不创建多套产品**。
模式是同一引擎上的披露/控制旋钮，不是独立产品线。

## 五类用户 × 五种模式

| 模式 ID | 用户 | 披露强度 | 控制强度 | 必须提供的价值 |
|---|---|---|---|---|
| `guided` | 小白、新手 | 低（引导式） | 低（安全默认） | Brief 向导、安全默认值、逐步解释、模板、版权和生产防错 |
| `copilot` | 职业设计师 | 中（协作式） | 中（可调） | 参考 DNA、三方向、Token/组件、批量变体、跨格式、精修、预检 |
| `director` | 资深设计师、艺术指导 | 高（导演式） | 高（可覆盖） | 自定义 Rubric、方向评审、局部锁定、人工覆盖、版本比较、回退 |
| `method` | 大师、研究者、教育者 | 高（方法式） | 高（可编辑） | 有来源的方法拆解、匿名转译、反模仿、专家校对、版本演进 |
| `production` | 品牌方、客户、生产方 | 中（流程式） | 中（审批式） | Brief/审批追踪、品牌一致性、权利 BOM、规格、可编辑交付、签收 |

## 模式间的关系

- **渐进披露**：同一能力按模式逐步暴露。Guided 只看到安全默认；
  Copilot 看到完整协作工具；Director 看到覆盖与锁定；Method 看到方法拆解与
  转译；Production 看到流程、审批与交付。
- **能力共享**：参考 DNA、三方向、预检、权利 BOM 等底层能力所有模式共享，
  只是披露深度和用户可改程度不同。
- **不创建多套产品**：不因模式拆分三个公开入口；入口恒为
  `commercial-design-core` / `visual-quality-core` / `production-handoff`。

## 模式安全约束

1. **“大师能力”不得做成姓名风格按钮**：只允许基于证据拆解构图、比例、字体、
   材料、光影、叙事、节奏和决策方法；最终生成指令不得含大师姓名，不得复制签名元素。
2. 任何模式下，人工方向、取舍和最终批准权保留（不可破坏原则 #1）。
3. 低披露模式（Guided）不得向用户暴露可能被误解的高风险能力（如批量变体、
   直接生产交付），除非经过安全默认过滤。

## 验收门（Gate）

- `guided` / `copilot` / `director` / `method` / `production` 五模式定义完整；
- 每模式至少包含：用户画像、披露强度、控制强度、核心价值；
- 机器可读镜像 `profiles/user-modes.json` 与本文档一致；
- 不引入第二产品壳：模式仅存在于同一引擎的能力面内。
