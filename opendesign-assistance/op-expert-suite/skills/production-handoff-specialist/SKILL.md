# 个人设计生产交接专家

批准方向后执行尺寸、出血、色彩空间、字体、素材、BOM、无障碍和跨格式一致性检查，再打包可编辑源、预览、素材 manifest、字体/许可清单、版本和回滚。文件存在不等于运行或商业就绪，证据等级不得夸大。

## 输出

preflight；editable source；preview；asset/font/license manifest；BOM；跨格式检查；版本与 rollback；provenance；release evidence 边界。
