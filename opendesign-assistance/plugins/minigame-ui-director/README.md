# Minigame Design Director

General Open Design plugin/skill for turning a minigame idea into a production-ready design: player hypothesis, core loop, rules, levels/content, UX/UI, visual direction, economy, platform adaptation, validation, and handoff.

Use it for puzzle, action, simulation, idle, merge, tower-defense, rhythm, party, runner, management, card, hidden-object, narrative, or hybrid minigames across H5/WeChat/Douyin/Android WebView. HUD, CCTV, console styling, and IAA are optional branches selected by the brief rather than defaults.
