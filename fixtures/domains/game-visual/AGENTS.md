# Module instructions

This module is the **frozen Game Visual Design Fixture / Runtime Reference** for
DESIGN-LAB. It is NOT an independent game product.

## Allowed (fixture scope)

- HUD / UI / icon / skin / interaction feedback / scene atmosphere / dynamic
  visual / asset specs / cross-platform visual regression / runnable visual
  fixture maintenance (build & tests).
- Consume only approved DESIGN-LAB design profiles.

## Forbidden (fail-closed)

- Mini-game collection platform, independent product line, release channel,
  advertising / IAA / monetization, operations, new gameplay systems,
  content-pack expansion, or any publish/growth roadmap.
- Any PR that re-introduces `launch-game`, `IAA`, `adSlots`, `release`,
  `monetization`, `nextContentPack`, or `平台运营` semantics into active
  paths is rejected by the boundary gate.

All runtime/build changes stay reversible and evidence-backed. No live
release, monetization, or production claims may be made from this fixture.
